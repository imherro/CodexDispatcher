# Codex Dispatcher v0.4.2

- 修复会话验证中临时出现 `JSON-RPC error -32603: workspace routing discovery timed out` 时直接失败的问题。
- 桌面模式从原 Codex 桌面应用读取配置会话的资料，避免为验证目标会话另经 SDK 发现路由。
- 只读操作遇到该明确的路由超时最多尝试三次；持续失败显示中文说明。派送前失败保留队列，恢复后自动通知。
- 发送结果不确定仍保留待确认状态，不因错误文字含“超时”而重复发送。
- 界面操作失败会记录操作名和错误，便于后续排查。

111 项测试通过，包含暂时超时恢复、三次重试上限、连续失败保留队列、恢复后只发送一次以及不确定发送不重试。验证不调用模型。

升级时从系统托盘退出旧版，再运行 `dist/v0.4.2/CodexDispatcher/CodexDispatcher.exe`。已有配置及通知历史保留。
