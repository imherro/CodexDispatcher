# Codex Dispatcher v0.4.0

- 新增 Windows 桌面桥接，由持有会话的原 Codex 桌面应用接收通知，解决空闲会话仍有 active writer 的派送问题。
- agent 工作时通知保留在持久队列，空闲后自动投递；忙碌不再因六次检查而失败，不中断当前任务。
- 编辑、开始 / 停止监测、立即检查使用图标按钮和悬停说明，操作列从 290 像素缩小至 118 像素。
- 每个 Worker 可编辑通知格式、实时预览、恢复默认。保留原文链接与通知 ID，不转发任务正文。
- 通知详情区分准备发送和已收到回执，桌面接收回执不伪造 Turn ID。
- 保留 SQLite 版本 2、旧配置、历史和去重记录。

桌面桥接使用本机 codex-app-tools 插件的管道协议，属于实验性集成；需要原 Codex 桌面应用运行，本机已登记调用来源。未登记时仍可使用原 SDK 派送模式。未知发送结果进入人工确认，不自动重发。

默认 mock 测试及隔离真实验收结果见当前 README 和验收 JSON。分发整个 `dist/v0.4.0/CodexDispatcher` 目录；升级时退出旧 Dispatcher 后运行新版。

本次真实验收确认桌面派送、忙碌持久排队和空闲投递；隔离 agent 读取 GitHub 遇到网络代理拒绝，完整端到端验收未通过，报告保留失败状态与清理结果。
