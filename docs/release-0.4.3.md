# Codex Dispatcher v0.4.3

- 修复保存 Worker 因 GitHub GraphQL 请求 EOF 而失败：保存不再检查 GitHub 连接。
- 已有 Worker 未更换会话时，使用已保存的项目资料做本机校验，通知格式等修改可以离线保存；新建或更换会话仍验证真实目标。
- GitHub 只读请求遇到 EOF、超时、连接重置和 HTTP 502/503/504 自动重试，最多三次、共用 45 秒预算。登录、权限、404 及限流错误不盲目重试。
- 持续临时断网时保留待发送通知，监测退避后继续，不因连续五次网络故障自动停掉。测试脚本的写操作不自动重试。

121 项测试通过，验证已有配置离线保存、临时网络失败恢复、队列不丢失及恢复后仅通知一次；测试未发送真实通知，未调用模型。

升级时从系统托盘退出旧版，再运行 `dist/v0.4.3/CodexDispatcher/CodexDispatcher.exe`。原有配置、通知格式与历史保留。
