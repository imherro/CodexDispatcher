# Codex Dispatcher v0.4.8

- 收紧 Worker 配置页行距和控件高度，合并检查间隔与启用开关；小屏幕支持滚动，保存按钮固定在底部。
- 允许监测中、agent 运行中或有待确认通知时保存配置，不再要求先停止运行。
- 后续检查读取新配置；倒计时按新间隔从保存时重新计算。正在执行的检查及已有通知保留原配置，不中断会话，不改变队列中的目标会话或通知内容。
- 保存不立即触发扫描；取消启用并保存会停止监测和后续派送。
- 更换目标会话后，重新开始监测或重启后恢复时，旧队列仍按原会话派送。

验证：162 项测试通过，包含运行中/待确认状态下保存、休眠监测应用新间隔、检查中的配置快照保留、下一轮读取新配置及原队列目标/通知格式保持不变、重启后恢复原目标队列。隔离 GUI 验收通过，配置页高度为 560；未发送实际通知或调用模型。

Windows 打包启动、GUI、数据库、内置 runtime、登录状态及独立启动读取桌面桥接配置均验证通过。
