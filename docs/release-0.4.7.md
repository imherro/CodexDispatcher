# Codex Dispatcher v0.4.7

- 分配规则中的 Assignee 明确显示为“GitHub 账号指派”，列表显示“指派给 账号”。填写真实 GitHub 用户名，不加 @。
- 按 Issue 的 Assignees 精确匹配，不区分大小写；本机读取仓库的账号可以不同。
- 通知已指派的打开 Issue 及后续新评论，无需正文点名。每个 Issue 和每条评论各通知一次，重复检查、重启和编辑原评论不会重复派发。
- 评论作者与指派账号一致时跳过，避免 agent 汇报引起循环；按 GitHub 真实作者字段判断。人与 agent 应使用不同账号。
- 首次监测也检查已有未通知的 Issue 和评论。发送前重新读取负责人及评论，取消指派、删除评论或关闭 Issue 后不再发送排队通知。保留配置和去重历史。
- 编辑窗口说明每种规则的匹配来源及通知次数。

验证：157 项测试通过，覆盖指派账号精确匹配、不接受 @、分页评论、真实作者过滤、重启去重、派送前取消指派和删除评论。隔离 GUI 验收通过，未发送实际通知，未调用模型。

Windows 打包启动、GUI、数据库、内置 runtime、登录状态及独立启动时读取桌面桥接配置验收通过。
